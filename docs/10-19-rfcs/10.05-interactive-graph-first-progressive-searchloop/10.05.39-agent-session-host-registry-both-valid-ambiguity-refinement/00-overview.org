* Status

Focused formal verification is complete. This RFC refines [[file:../10.05.38-agent-session-host-registry-adjudication-decision-certificate/00-overview.org][RFC 10.05.38 — Agent Session Host Registry Adjudication Decision Certificate]]. The Lean source and direct audit compile, all 20 theorem declarations are axiom-free, and the module is imported by the proof-package root.

This RFC verifies semantic witness shape, provenance-root preservation, strict ambiguity reduction, and finite evidence bounds. It does not prove that the chosen terminal-semantics abstraction or discriminator implementation is adequate. No Rust implementation is authorized in this session.

* Problem

RFC38 correctly keeps a =valid/valid= terminal pair quarantined because its decision relation has no entailment constructor for that judgment pair. Permanent quarantine is safe but incomplete.

Additional evidence may resolve the dispute in two ways:

- an equivalence witness proves that both captures represent the same terminal semantics and may be coalesced;
- an incompatibility witness proves different terminal semantics and carries a discriminator selecting the supported terminal.

Refinement must not mutate acquisition facts. The accepted and conflicting provenance roots are immutable indices across every step. Only their semantic interpretation and ambiguity rank may change.

Evidence acquisition must also be bounded. Spending a round without strictly reducing certified ambiguity is not progress.

* Equivalence witness law
:PROPERTIES:
:ID: ASP-RFC-10.05-ASBR-EQUIVALENCE
:END:

#+name: registry-both-valid-equivalence-law
#+begin_src typst
#let ValidEq(a, c, w) = $upright("ValidEquivalenceWitness")(#a, #c, #w)$
#let RootA(w) = $upright("acceptedProvenanceRoot")(#w)$
#let RootC(w) = $upright("conflictingProvenanceRoot")(#w)$
#let SemA(w) = $upright("acceptedSemantics")(#w)$
#let SemC(w) = $upright("conflictingSemantics")(#w)$

$
  forall a, c, w,
  ValidEq(a, c, w) =>
  RootA(w) = a and RootC(w) = c and SemA(w) = SemC(w).
$
#+end_src

Equivalence entails only =coalescedEquivalent=. It cannot silently prefer one terminal.

* Incompatibility witness law
:PROPERTIES:
:ID: ASP-RFC-10.05-ASBR-INCOMPATIBILITY
:END:

#+name: registry-both-valid-incompatibility-law
#+begin_src typst
#let ValidNe(a, c, w) = $upright("ValidIncompatibilityWitness")(#a, #c, #w)$
#let SemA(w) = $upright("acceptedSemantics")(#w)$
#let SemC(w) = $upright("conflictingSemantics")(#w)$
#let Disc(w) = $upright("discriminatorDigest")(#w)$

$
  forall a, c, w,
  ValidNe(a, c, w) => SemA(w) != SemC(w) and Disc(w) != 0.
$
#+end_src

A nonzero discriminator digest is identity evidence, not proof of discriminator correctness. Executable discriminator conformance remains a later boundary.

* Monotone refinement law
:PROPERTIES:
:ID: ASP-RFC-10.05-ASBR-REFINEMENT
:END:

#+name: registry-both-valid-refinement-law
#+begin_src typst
#let Step(s, n) = $upright("RefinementStep")(#s, #n)$
#let RootA(s) = $upright("acceptedProvenanceRoot")(#s)$
#let RootC(s) = $upright("conflictingProvenanceRoot")(#s)$
#let Rank(s) = $upright("ambiguityRank")(#s)$
#let Budget(s) = $upright("evidenceBudget")(#s)$

$
  forall s, n,
  Step(s, n) =>
  RootA(n) = RootA(s) and RootC(n) = RootC(s) and
  Rank(n) < Rank(s) and Budget(n) < Budget(s).
$
#+end_src

Root drift, unchanged ambiguity, and self-loops are invalid refinement steps.

* Lean contract embedded in Org

#+name: registry-both-valid-refinement-lean-contract
#+begin_src lean
def ValidEquivalenceWitness
    (acceptedRoot conflictingRoot : Nat)
    (witness : SemanticEquivalenceWitness) : Prop :=
  witness.acceptedProvenanceRoot = acceptedRoot ∧
  witness.conflictingProvenanceRoot = conflictingRoot ∧
  witness.acceptedSemantics = witness.conflictingSemantics

def RefinementStep
    (current next : AmbiguityRefinementState) : Prop :=
  next.acceptedProvenanceRoot = current.acceptedProvenanceRoot ∧
  next.conflictingProvenanceRoot = current.conflictingProvenanceRoot ∧
  next.ambiguityRank < current.ambiguityRank ∧
  next.evidenceBudget < current.evidenceBudget
#+end_src

* Lean-discovered obligations

Lean rejects false equivalence, missing discriminator identity, accepted-root drift, conflicting-root drift, unchanged ambiguity, refinement self-loops, and refinement after rank zero.

Every refinement run is bounded by both the initial ambiguity rank and initial evidence budget. The proof therefore excludes unbounded “ask for more evidence” loops even when the state remains quarantined.

The model also exposes its own next assumption boundary. =TerminalSemantics= is currently an abstract pair of outcome and effect digests. Equality of this structure is only useful if that abstraction is adequate, and a nonzero discriminator digest does not prove executable discriminator correctness. Those are explicit future proof obligations rather than hidden assumptions.
