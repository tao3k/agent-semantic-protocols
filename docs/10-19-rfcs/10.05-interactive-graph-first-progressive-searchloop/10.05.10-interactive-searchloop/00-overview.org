#+title: Interactive SearchLoop
#+property: rfc_layer interactive-searchloop

* Ownership

This layer owns agent-facing progressive transitions: discovery, compact
inspection, focused expansion, exact materialization, merge, stop, and reroute.
The CLI is one adapter and is not the protocol state machine.

It does not own graph ranking internals, cache identity, or formal audit
execution.
