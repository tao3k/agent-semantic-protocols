* Scope

This directory decomposes the Rust-readiness refinement of the Codex
Multi-Agent v2 downstream LifeSession contract.  The parent RFC owns observed
Host semantics and the cross-module invariants.  These modules own the detailed
close protocol, Rust aggregate boundary, and proof correspondence.

* Cross-module invariant

Binding authority, close authority, replacement authority, and presentation
visibility are independent.  No module may infer one from another.  All Host
effects use revision CAS, durable intent/outbox, a stable dispatch key,
intent-indexed receipts, and a delivered aggregate CAS.
