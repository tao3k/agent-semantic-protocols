#+title: RFC 10.15.02.06.01 — LifeSession close and canonical path release
#+options: toc:2

* Scope

Closing a Codex child is a durable protocol.  Host archive visibility, the
persisted close edge, shutdown dispatch, observed termination, canonical path
release, and replacement reservation are independent facts.

* State contract

The close projection has these phases:

- =live=;
- =close-intent-durable=;
- =shutdown-requested=;
- =host-terminated=;
- =path-released=; and
- =BlockedHostCapability=.

=AcceptArchiveProjection= changes presentation only.  It neither advances the
close phase nor authorizes replacement.  =ReserveReplacement= requires a
path-release receipt and a strictly newer physical generation.

$ live -> intent -> shutdown -> terminated -> released $

$ shutdown -> blocked -> terminated $

$ replacement(s, g') =
  (phase(s) = released)
  and closeIntent(s)
  and terminationReceipt(s)
  and pathReleaseReceipt(s)
  and (g' > physicalGeneration(s)) $

$ archive(s) != termination(s) quad and quad archive(s) != release(s) $

$ admit(s, e) =
  (expectedRevision(e) = revision(s))
  and (physicalGeneration(e) = physicalGeneration(s))
  and stableKey(s, e) $

$ close(s) != live => durableDispatch(s) = no $

* Blocked Host capability

=BlockedHostCapability= records a durable close edge and shutdown dispatch for
which the Host has not supplied termination.  It authorizes neither path
release nor replacement.  A late termination receipt resumes the same stable
dispatch key and advances the existing intent; it does not start another close
transaction or ask the agent to choose an administrative repair command.

* Required properties

- Archive may occur before close, after close, or not at all.
- A persisted close edge does not prove termination.
- Termination does not prove canonical path release.
- Path release before termination is rejected.
- Duplicate effects under one stable key are idempotent.
- Stale revision, generation, and stable-key completions are rejected.
- Same-generation replacement is rejected.
