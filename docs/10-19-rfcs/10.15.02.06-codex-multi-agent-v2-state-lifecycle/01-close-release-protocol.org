#+TITLE: Multi-agent resident-slot close and release protocol

* Scope

Close and replacement operate on one resident slot inside a
=MultiAgentLifeSession=.  They never close the root session merely because one
agent exits, and they never count temporary agents as resident replacements.

* Ordered transition

#+begin_example
incumbent
  -> archive-intent durable
  -> dispatch authority revoked
  -> host shutdown requested
  -> host termination receipt indexed
  -> canonical path release receipt indexed
  -> vacant
  -> newer replacement generation
#+end_example

Missing transport, timeout, archive visibility, or a Runtime Server restart
cannot skip an edge.  A slot cannot contain incumbent and replacement states at
the same time because =ResidentOccupancy= makes that state unrepresentable.
