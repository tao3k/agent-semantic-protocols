#+title: 00.77 Proof-Carrying Selective Disclosure
#+startup: overview

* Status

This module specifies selective evidence disclosure and orthogonal cache reuse.
It does not implement a Rust or Python search runtime.

* Problem

A one-hop chain summary reduces presentation cost, but a router still needs a
principled rule for expanding only the transition edges required by the current
decision.  The rule must prevent three shortcuts:

1. omitting a required trust edge,
2. disclosing an edge outside the committed chain, and
3. treating one cache lane as proof for another cache lane.

Search cache, proof-verification cache, and model-prefix cache optimize different
work.  A hit in one lane cannot authorize credit in another lane.

* Contract

** ASP-RFC-10.05-PCSD-REQUEST

A disclosure request MUST bind a certified chain summary, policy digest, query
digest, and a canonical strictly increasing list of required edge indices.

** ASP-RFC-10.05-PCSD-IDENTITY

A disclosure receipt MUST bind the same summary, policy digest, and query
digest as its request.

** ASP-RFC-10.05-PCSD-COVERAGE

Required edges MUST be an ordered sublist of disclosed edges.  Every disclosed
edge index MUST be below the summary's committed edge count.

** ASP-RFC-10.05-PCSD-MINIMAL

When a receipt discloses exactly the canonical required edges, it is
token-minimal among all valid receipts for that request.

** ASP-RFC-10.05-PCSD-AUTHORIZATION

A decision is authorized only when both the expanded chain proof and the
disclosure receipt are valid.  Cache-hit flags are not authorization evidence.

** ASP-RFC-10.05-PCSD-SEARCH-CACHE

A search-cache key MUST bind query digest, provider digest, and registry
snapshot digest.  A hit may eliminate provider calls only.

** ASP-RFC-10.05-PCSD-PROOF-CACHE

A proof-cache key MUST bind chain digest, policy digest, and Lean/AXLE audit
digest.  A hit may eliminate repeated proof checks only.

** ASP-RFC-10.05-PCSD-MODEL-CACHE

A model-prefix-cache key MUST bind model digest and serialized-prefix digest.
A hit may eliminate uncached model-prefix tokens only.

** ASP-RFC-10.05-PCSD-COST

Cache reuse MUST preserve disclosed-token cost and LLM-round count unless a
separate proof justifies changing those coordinates.  Search, proof, and model
cache credits MUST remain orthogonal.

** ASP-RFC-10.05-PCSD-ROUTER

The router SHOULD disclose the exact required-edge sublist when it is valid.
It MUST request another inspect step when identity, coverage, range, chain
verification, or cache binding is missing.

* Org-Babel Typst model

#+name: proof-carrying-selective-disclosure-math
#+begin_src typst
#let summary = (
  chain-digest: 9001,
  policy-digest: 71,
  query-digest: 81,
  edge-count: 5,
)

#let required-edges = (1, 3)
#let disclosed-edges = (1, 3)

#let cache = (
  search-hit: true,
  proof-hit: false,
  model-prefix-hit: true,
)

#let baseline = (
  provider-calls: 1,
  proof-checks: 1,
  disclosed-tokens: disclosed-edges.len(),
  uncached-model-tokens: 600,
  llm-rounds: 1,
)

(
  identity-bound: true,
  ordered-coverage: required-edges == disclosed-edges,
  all-edges-in-range:
    disclosed-edges.all(edge => edge < summary.edge-count),
  token-minimal:
    disclosed-edges.len() == required-edges.len(),
  provider-calls:
    if cache.search-hit { 0 } else { baseline.provider-calls },
  proof-checks:
    if cache.proof-hit { 0 } else { baseline.proof-checks },
  disclosed-tokens: baseline.disclosed-tokens,
  uncached-model-tokens:
    if cache.model-prefix-hit { 0 }
    else { baseline.uncached-model-tokens },
  llm-rounds: baseline.llm-rounds,
)
#+end_src

The expected record keeps proof checks, disclosed tokens, and LLM rounds while
eliminating provider calls and uncached model-prefix tokens.  This demonstrates
that the two hits credit only their own cost coordinates.

* SearchLoop consequence

The agent receives the smallest ordered evidence slice that can answer the
current decision.  Further inspect actions are generated from missing required
edges rather than from a complex search CLI grammar.  The summary and three
cache identities remain stable, content-addressed prefixes, while the disclosed
edge slice changes progressively with the agent's decision state.
