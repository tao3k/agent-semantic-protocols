#+title: RFC 10.05.87 — SearchRoute Cache Rejoin Configuration Identity
#+startup: overview

* Status

Draft proof-bearing extension of RFC 10.05.86.

* Abstract

Joint quorum membership is insufficient when votes from another membership
generation can be replayed.  This RFC binds every transition vote and
certificate to configuration epoch, old-membership digest, and new-membership
digest.

* Normative clauses

** ASP-RFC-10.05-CRCI-IDENTITY — Configuration identity is complete

Configuration identity MUST contain epoch, old-membership digest, and
new-membership digest.

** ASP-RFC-10.05-CRCI-VOTE — Vote ledger keys include configuration identity

Signer votes MUST be queried by configuration identity, term, and index.
Certificate wrapper fields alone are insufficient.

** ASP-RFC-10.05-CRCI-REPLAY — Cross-generation votes fail closed

A vote stored under another epoch or membership digest pair MUST NOT validate
the current transition certificate.

** ASP-RFC-10.05-CRCI-UNIQUENESS — One configuration slot has one receipt

Valid certificates with equal configuration identity, term, and index MUST bind
equal receipts.

* Mathematical model

#+name: searchroute-cache-rejoin-configuration-identity-model
#+begin_src typst
#let identity(epoch, old, new) = (epoch: epoch, old: old, new: new)
#let vote-key(configuration, term, index) = (
  configuration: configuration,
  term: term,
  index: index,
)
#let current = identity(9, "old-A", "new-B")
#let replayed = identity(8, "old-A", "new-B")
#assert(vote-key(current, 4, 10) != vote-key(replayed, 4, 10))
"ok"
#+end_src

  and upright("slot")(C_1) = upright("slot")(C_2)

#assert(type(uniqueness) == content)
"ok"

* Lean correspondence

| RFC clause | Lean witness |
|-
| CRCI-VOTE, CRCI-REPLAY | =vote_from_other_configuration_cannot_validate_certificate= |
| CRCI-IDENTITY, CRCI-UNIQUENESS | =valid_same_configuration_certificates_bind_same_receipt= |

* Remaining proof boundary

Membership digests are abstract.  A follow-up RFC must bind them to canonical
ordered member identities, voting weights, and failure-domain constraints.
