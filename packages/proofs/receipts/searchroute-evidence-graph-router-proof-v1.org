* Lean-discovered protocol corrections

- Static graph feasibility does not imply runtime readiness.
- Receipt binding does not repair an unresolved or projection-incompatible
  provider route.
- Recoverable capability state cannot participate in route selection.
- Catalog optimality is conditional on certified feasibility.
- Universe optimality additionally requires completeness over executable
  candidates, not merely semantic paths.

* Remaining boundary

Python Graph Turbo does not yet implement the new shared certificate.  The next
proof layer must cover capability expiry, bounded retry termination,
warm-index identity, and canonical route-digest binding.
