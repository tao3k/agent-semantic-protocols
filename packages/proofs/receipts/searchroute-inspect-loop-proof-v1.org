* Proof boundary

The model proves that every valid prune or inspect decision strictly decreases
the sum of positive frontier credits. It separately proves that safe pruning
and inspect refinement conserve candidate-universe coverage. A full-budget
valid trace therefore closes and returns a selected candidate that is globally
optimal over the bound candidate-universe snapshot.

It does not claim optimality for an open world, a stale snapshot, or an inspect
step without a refinement coverage receipt.

* Lean-discovered RFC defects

1. A non-strict credit rule permits an exact self-replacement with unchanged
   state and unchanged work. Strict decrease is normative.
2. Strict decrease alone proves termination but not search correctness. An
   inspect step can consume work while dropping unresolved candidates.
   =RefinementCovers= is therefore a separate normative receipt.
3. A closed loop proves global optimality only when candidate-universe coverage
   has been conserved for the same snapshot.
