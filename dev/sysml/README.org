* Scope and ownership

=project.sysml= and =dev/sysml/search-engine.sysml= follow the same strict
OpenSysML v2 standard used in Marlin Agent CORE (=sysml -strict -validate -self-check -no-record-cache=).
Models own structural identities, transport boundaries, generation lifecycles,
and requirement allocations; generated views and benchmark artifacts remain
under =target/=.
